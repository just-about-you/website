Accessibility

What is tested, and what falls short.

Most accessibility statements describe an intention. This one lists what is asserted by a test that would fail, and is equally exact about the checks on this site that are still done by hand.

In the app, asserted

Text at 200% on a small screen

Every walkthrough step is checked at double text size on a 360 pixel screen. Nothing may truncate or overflow.

Reduce motion means no motion

Turn it on and the walkthroughs give the same steps and the same words with nothing moving — not a shortened animation, none.

A screen reader gets the whole step

Each step announces as one piece rather than as fragments that can be interrupted, and in the order it is meant to be heard.

Where it falls short

The failure this section used to name is fixed. What is left is a gap in colour, and it is a real one.

The contrast exemption is gone

This card used to say one colour family’s main button sat at 3.32 where the standard asks for 4.5. That family was deleted, and no exemption replaced it: all fifteen themes are held to 4.5 for text and 3 for anything else, measured on the colour you actually see on a translucent card.

It is recorded rather than removed because the practice is the point. A page that has never listed a failure is a page nobody has looked at hard enough.

There is no maximum-contrast theme

Every theme meets the bar, and none of them is built to exceed it. A colourless, maximum-contrast option existed and was removed when the roster was rebuilt.

This page will not describe one until there is one to describe, which is why you will not find a maximum-contrast mode named anywhere else here.

On this site

Checked before anything is published

Colour contrast is computed from the stylesheet itself and fails the build if any pair drops below the standard. So does a skip link, a page language, alt text on every image, and a list of sentences these pages are not allowed to publish.

Checked by hand, on five pages

Reflow at 360 pixels is not automatic. It runs in a browser someone opens, and it covers five of the nineteen pages here: the landing page, features, privacy, help and about.

This card used to be part of the one beside it, which said both were verified before the site went anywhere. Only one of them was. Splitting them is the honest version until the reflow check runs on its own.

Tell us if we have missed something

An accessibility problem is a bug, and we would rather hear about it than have you work around it. See contact.
